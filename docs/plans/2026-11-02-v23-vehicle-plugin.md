# 油记 2.3：车辆数据走契约，沃尔沃搬成私有插件 — 实施文档

- 设计：`docs/specs/2026-10-27-plugins.md` 的第 2 阶段（第 2、4、5、6、9、10 节；D2、D3、D6、D16，用户 2026-11-02 定）。
- 沃尔沃插件是私有的：代码、协议、凭据抓取和用真实数据的测试都在插件的私有仓库，它的计划在插件自己的文件夹里（beta.2 开工时建）。本文只写油记这一边，以及两边在哪里对接。
- 约定沿用 `CLAUDE.md` 和 2.2 实施文档：纯逻辑放 `common/`；入口只从一个模块导入；泛型写成函数声明或 `<T,>`；可选属性不传 `undefined`。
- 每个测试版：先写 CHANGELOG → `npm run bump -- x.y.z` → `npm run check` 和 `XXYH_ROOT=E:/GitHub/xxyh npm test` 都退出 0 才提交 → `git tag -s`，不推送 → 跑 FuelNote Check、看完截图 → 再请用户看剩下的项目。
- 验收的原则（D16）：除了加油停车提示，界面和结果都和 2.2 一样。

## 2.3.0-beta.1：车辆数据走契约（沃尔沃仍是内置）

- [ ] `common/plugin.ts`：契约加 `vehicles`、`trips`、`vehicle_status`、`service` 的校验和整理（缺字段或类型不对的项丢掉）。`Trip`、`VehicleStatus` 沿用 `providers/types.ts`，`ServiceVisit` 沿用 `common/types.ts`，工单多带项目整理的三项。能力检查：有 `trips`、`vehicle_status`、`service` 之一的必须有 `vehicles`。超时：`vehicles`、`trips` 20 秒，`vehicle_status` 10 秒，`service` 60 秒（待定第 1 条）。
