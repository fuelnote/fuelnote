- 沃尔沃插件是私有的：代码、协议、凭据抓取和用真实数据的测试都在插件的私有仓库，它的计划在插件自己的文件夹里（beta.3 开工时建）。本文只写油记这一边，以及两边在哪里对接。

- 验收的原则（D16）：除了加油停车提示、养修（设计 3.4 节）、记录的来源和费用的标题（3.5、3.6 节），界面和结果都和 2.2 一样；费用页的标题都和 2.2 一样。

1. 开工前：在手机上量小组件的内存；画第十八轮其余的稿；用户选稿里的 A/B。
2. beta.1：行程、车况走契约，沃尔沃仍是内置；去掉加油停车提示（D2）。没有新界面，不等画稿。

5. 2.3.0：用户说「发版」时发布。
